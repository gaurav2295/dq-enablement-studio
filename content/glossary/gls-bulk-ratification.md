## Definition

Approving a **queue** of proposed links or vocabulary entries by ratifying the **principle** that
decides them, rather than clicking through each row — with the principle, the method and the date
recorded on every row it touched.

## Usage

It exists because the linkage queue is thousands of rows long and unratified rows are worth
nothing. It stays honest because the record survives: any row can be traced back to the rule that
admitted it, and a withdrawn principle identifies exactly which rows to revisit.

The bar for admitting a link — two independent signals, never lexical overlap alone — is set in
[[prn-governed-ratification]].
