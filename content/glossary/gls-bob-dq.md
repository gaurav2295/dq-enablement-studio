## Definition

**The DQ variant of BOB** (Business Outcomes Blueprint).

**Variants change the evidence source, never the method.**

## Usage

That one sentence is the whole variant doctrine. `#bob-dq` uses data-quality rule results as its
evidence; a future variant would swap in a different evidence source and walk the *same* chain —
business outcome → value lever → key issue → DQ rule — with the same tier rules and the same
honesty language.

> [!important]
> If a proposed variant needs the method changed, it is not a variant. Either the change belongs
> in the method for everyone, or the thing being proposed is a different offering.

Written `#bob-dq` in internal material. Like every internal name it stays out of the client
room — see [[gls-client-instrument]].
