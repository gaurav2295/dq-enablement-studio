## Definition

`bob-client-project-spec` — the **travelling artefact** between the two instruments: what the canvas
exports and dq-studio imports. Outcomes selected, levers in play, key issues, the rules those imply,
and the scope they run against.

## Usage

It is a **contract**, which is what makes the hand-off survivable: the canvas can change how it
looks and the Studio can change how it derives, as long as the spec's shape holds.

Everything in it is client-safe vocabulary — the canvas is a
[[gls-client-instrument|client instrument]], so no internal tool names, rates or hours travel in
the spec.
