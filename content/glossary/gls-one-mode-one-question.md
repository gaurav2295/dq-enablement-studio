## Definition

**The organising principle of the instrument: each mode answers exactly one question and refuses
the others.**

If two modes answer the same question, one of them is wrong (A22, 2026-08-05).

## Usage

This is the test applied whenever a mode is proposed, extended or argued about. "Where does this
go?" is answered by asking what question the new thing answers, then finding the single mode
that owns that question — not by adding it wherever it fits most easily.

The consequences show up all over the vocabulary:

- The canvas carries **no duration at all** — duration is Solution Proposal's question.
- [[gls-the-package]] owns **no question**; it is the running answer, visible everywhere.
- [[gls-internal-workbench]] holds the questions the client room must never be asked.

> [!tip]
> "Refuses the others" is the load-bearing half. A mode that merely *deprioritises* the other
> questions still lets them creep back in, and the modes converge into one crowded screen.
