## Definition

The stated strength of a figure — how well evidenced it is — shown next to the number rather than
buried in a footnote. The third of the three mandatory companions of any currency figure.

## Usage

Confidence is not a hedge, it is information: a figure computed from a
[[gls-provenance|field-proven]] rule run against real client data and one computed from a derived
rule and a benchmark assumption are both legitimate, and they are not the same claim.

Labelling lets the honest version of a number survive the slide it ends up on. An unlabelled
figure gets read as certain, whatever the author intended.
