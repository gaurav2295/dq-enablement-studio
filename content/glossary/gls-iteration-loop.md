## Definition

The design → generate → run → review → refine cycle that improves a rule set. **dq-studio owns the
only one** in the chain.

## Usage

The division is deliberate. The canvas states an intent once and exports it; vector-studio
elevates finished results; neither iterates. Concentrating the loop in one instrument is what stops
three tools each holding a slightly different version of the same rule.

The practical consequence for a consultant: fix it in the Studio and regenerate. A hand-edit
downstream is lost at the next generation and, worse, invisible to the harness that would have
judged it.
