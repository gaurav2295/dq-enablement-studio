## Definition

A version of the offering that changes the **evidence source**, never the method — `#bob-dq` uses
DQ rule results; other variants would use other evidence.

## Usage

**One spine, many lenses.** The chain — outcome → lever → issue → evidence → value → action — is
the asset; what feeds the evidence step is the variable. Reading it the other way round (a new
variant means a new method) is how an offering fragments into several unrelated ones.

Do not confuse this with a rule pattern's *block variant* / *deletion variant*, which are shapes
inside one pattern — see [[gls-parity-pair]].
