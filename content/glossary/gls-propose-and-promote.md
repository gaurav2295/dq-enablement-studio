## Definition

Two distinct acts in a rules-first conversation:

| Act | Who / what does it | Effect |
|---|---|---|
| **Propose** | A rule picked in the explorer | Proposes the measures its value lever reaches — band shown **greyed** |
| **Promote** | A facilitator action | Writes the same selection state the canvas *Add* writes |

## Usage

A rule pick is a **statement, not a claim**: the greyed band says "this is what that lever
reaches", and nothing moves in [[gls-the-package]] headline until a human promotes it.
**Promote is the only way a rules-first pick moves the headline.**

Value still aggregates at the [[gls-value-lever]] and only there. Promoting a rule does not give
the rule a value; it selects the lever the rule evidences.

> [!important]
> The greying is the honesty mechanism. It renders the difference between *stated* and *claimed*
> visible in the room, so a browsing session cannot silently accumulate into a number the client
> thinks was agreed.

Because Promote writes exactly what canvas *Add* writes, the outcome-first and rules-first paths
converge on one selection state — there is no second model to reconcile.
